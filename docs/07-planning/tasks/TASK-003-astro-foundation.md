## Existing Implementation to Reuse

apps/web/ contains only .gitkeep. The root tsconfig.base.json contains the approved strict TypeScript baseline. No Astro application, package manifest, lockfile, source page, or application configuration exists. Reuse the existing directory and TypeScript baseline; do not duplicate root configuration.

## Allowed Changes

- Add apps/web/package.json with only the metadata and commands needed to run and build this Astro application.
- Add apps/web/package-lock.json generated by npm for reproducible installation.
- Add apps/web/tsconfig.json extending ../../tsconfig.base.json with only Astro-required application settings.
- Add apps/web/src/pages/index.astro containing a minimal static HTML placeholder sufficient to verify that Astro renders a public page. It must contain no editorial content or product feature.
- Add apps/web/astro.config.mjs only if the installed Astro version requires it for this minimal application; otherwise omit it.
- Remove apps/web/.gitkeep after the real application files are added.

## Dependencies

- Direct dependency proposed: astro only, in apps/web/package.json. Pin the resolved version through package-lock.json.
- Package manager proposed: npm, scoped to apps/web/. No root workspace or package manager configuration.
- Do not add other direct dependencies or integrations. If Astro cannot build without another direct dependency, report PLAN MISMATCH before expanding this Task.

## Forbidden Changes

- No CMS, database, API, authentication, editorial model, search, advertising, analytics, consent, or deployment integration.
- No public Article, Category, Author, institutional, SEO, sitemap, RSS, or advertising implementation.
- No client-side framework, hydration, adapter, hosting provider, shared package, infrastructure, or root workspace setup.
- Do not modify the root tsconfig.base.json, approved ADRs, backlog, or unrelated files.
- Do not add lint, test, CI, or general validation tooling belonging to separate backlog work.

## Acceptance Criteria

- AC-01: apps/web/ has a runnable Astro application and only the files allowed above.
- AC-02: npm ci succeeds from apps/web/ using the committed package-lock.json without recalculating or changing it.
- AC-03: The Astro build succeeds and emits a static homepage from the minimal index.astro file.
- AC-04: apps/web/tsconfig.json extends the root strict baseline; strict checking is not disabled.
- AC-05: The generated homepage is readable HTML with no project-owned client-side JavaScript or product feature.
- AC-06: Git changes are limited to this Task, with no additional direct dependency beyond astro.

## Required Tests / Validation

- Inspect the manifest and lockfile for the declared direct dependency and reproducible install.
- From apps/web/, run npm ci and then the build command defined in apps/web/package.json.
- Inspect the generated homepage for AC-05.
- Inspect the application tsconfig for AC-04.
- After npm ci and the build, inspect Git status and changed files; confirm that neither command modified any unexpected versioned file, then verify AC-01 and AC-06.
- Report any check that cannot run; do not mark VERIFIED unless the required checks pass.
